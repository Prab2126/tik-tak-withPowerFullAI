# Tik Tak Toe

This is a project where i create a tik tak toe where u can play with AI with different modes as well as u can do pvp battle with friend.

## AI Mod

- `Easy`
  - Easy one is very easy u winning chance is high.
- `Medium`
  - Medium One of the tuf but can be win. The chance is 80% to loss
- `Hard`
  - Hard one is so much tuf u have 95% chance to loss the game
